# HIghcloud_airlines_analysis_Project_Excel-_
Project report 
The project analyzes airline operational and performance data to identify trends, inefficiencies, and business insights.

The analysis includes data cleaning, transformation, and visualization.

Tools used: Excel, SQL, Power BI, and Tableau.

SQL was used for data querying and transformation.

Excel was used for initial data cleaning and exploratory analysis.

Power BI and Tableau were used to create interactive dashboards and visualizations.

The goal of the project is to analyze airline performance metrics such as flight delays, cancellations, passenger trends, and operational efficiency.
